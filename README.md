# Learning about Version Control

Author: Ankit Chhikara

Solving merge conflicts takes conscious effort, but I can do it!

The most useful thing about version control is that it helps us keep track of entire history of codebase. Say if I have been working on changes to the code and suddenly realise that I started itself in the wrong way and it is better to start over, then version control helps me in going back to the last commit before I started making changes for me to start over.
